# AeroPrecipe

- **URL**: https://aeroprecipe.com
- **Fecha de investigación**: 2026-11-14

## Problema que resuelve

Centraliza y estandariza cientos de recetas de AeroPress (incluyendo campeonatos mundiales) con temporizadores interactivos, evitando buscar recetas dispersas en blogs o videos.

## Usuarios objetivo

Usuarios de AeroPress (principiantes y competidores) que buscan explorar variaciones por ratio, molienda, temperatura y método estándar o invertido.

## Features detectadas

- Base de datos con 300-350+ recetas de AeroPress (campeones, baristas y comunidad)
- Temporizadores paso a paso en tiempo real
- Perfil personal, envío de recetas, votos, comentarios y notas privadas
- Guardado de configuración de molino por defecto
- Web + app móvil complementaria ("We Make Coffee")

## Pricing

- **Free**: Navegación web básica y uso limitado en app
- **Lifetime Membership**: Pago único de USD 19 para acceso ilimitado en web, app móvil y actualizaciones futuras

## Posicionamiento

El repositorio de referencia especializado exclusivamente en AeroPress.

## Diferenciadores

Nicho 100% enfocado en AeroPress con catálogo curado de campeonatos mundiales y formato unificado (orientación estándar vs. invertida).

## Notas del investigador

Excelente referencia de UX para un método único, pero limitado exclusivamente a AeroPress.
